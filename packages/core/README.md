# @maestroq/core

Shared types, schemas, and config loader for [maestroq](https://github.com/rezsekmv/maestroq).

This is an internal package — you almost certainly want the CLI ([`maestroq`](https://www.npmjs.com/package/maestroq)) instead. See the [project README](https://github.com/rezsekmv/maestroq#readme) for setup and usage.
