# @maestroq/daemon

The long-running job-queue server for [maestroq](https://github.com/rezsekmv/maestroq).

This is an internal package — install the CLI ([`maestroq`](https://www.npmjs.com/package/maestroq)) and run `maestroq daemon start` instead of importing this directly. See the [project README](https://github.com/rezsekmv/maestroq#readme) for setup and usage, and [`docs/architecture.md`](https://github.com/rezsekmv/maestroq/blob/main/docs/architecture.md) for the daemon's lifecycle, RPC framing, and crash-recovery design.
